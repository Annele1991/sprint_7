# sprint_7
Proyecto del sprint 7
🚀 Análisis de Datos con Python y Pandas
Este proyecto se centra en la aplicación de los fundamentos de Python para la manipulación, limpieza y análisis exploratorio de datos (EDA), utilizando principalmente la librería Pandas.

🛠️ Herramientas y Tecnologías
El proyecto demuestra el uso de las siguientes herramientas y librerías, esenciales en el campo de la ciencia de datos:

Python: Lenguaje de programación base.

Pandas: Librería clave para el manejo de estructuras de datos (DataFrame) y el análisis.

Google Colab / Jupyter Notebooks: Entorno de ejecución interactivo.
